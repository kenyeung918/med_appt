# Medical Appointment Booking

## 📌 Project Scenario
**StayHealthy Inc.** is a non-profit organization dedicated to improving healthcare facilities in remote areas with minimal medical resources. As part of the **Go Digital Initiative**, the Executive Director has requested the development of a website that connects patients with doctors anytime, anywhere.

---

## 🎯 Problem Statement
Surveys conducted by StayHealthy revealed that patients in remote areas struggle to find doctors within a 50-mile radius, often facing long wait times. This has led to life-threatening emergencies and lost lives. With increasing internet availability, the initiative aims to provide timely access to general physicians and specialists.

---

## 🛠️ Project Requirements
The platform must be:
- **User-friendly, intuitive, and accessible**
- Capable of connecting patients with doctors for consultations and prescriptions

### Core Features
1. **Medical Appointments Online**
   - Schedule, reschedule, or cancel appointments
   - View available doctor time slots
   - Receive reminders/notifications

2. **Doctor Listing**
   - View available doctors with ratings and reviews
   - Search for doctors by name

3. **Consultation Feedback**
   - Rate consultations on diagnosis, communication, and effectiveness

4. **Profile Management**
   - User sign-up with mandatory details (name, address, phone, age, blood group, medical records)
   - Ability to update personal details

5. **Navigation**
   - Simple, minimal-click navigation across the site
